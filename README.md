# 企业级智能售前 Agent 平台 (Enterprise AI-Native Pre-sales Platform)

面向企业级售前咨询场景的 Agent 平台原型。针对原有模式中工具硬编码、多轮对话信息截断、优化靠人工翻日志等业务瓶颈，本项目构建了一套**工具可插拔、状态可管控、执行可追溯**的 Agent 执行底座（Harness Runtime），并跑通了“失败分析 → 变更提案 → 人工审核 → 回归验证”的**AI 自进化闭环**。

## 1. 工程目标与非目标

### 1.1 工程目标
* 提供可本地运行、可演示、可自动化回归测试的售前 Agent 底座。
* 以 `LLMProvider` 和 `Tool` 双抽象及注册表构建底层 Runtime，彻底解耦模型接入与业务逻辑。
* 通过 **Harness 运行时**承载 ReAct 决策循环，实现统一的执行护栏（单工具 10s 超时、总预算 60s、最多 6 步）。
* 实现多轮会话状态不丢失：底层统一管理 8000 Token 输入预算，超 80% 触发四级动态压缩。
* 依托 Trace 采集构建**自进化评测闭环**，将异常转为 Observation 回灌自我修正，支持 Docker 隔离环境与自动化门禁拦截。

### 1.2 非目标
* 不将本地事件与指标解释为真实商业收益；执行轨迹不包含隐藏思维链。
* 不实现真实的自动化支付、实时坐席接管及多进程高并发调度。

## 3. 核心架构亮点设计

* **Harness 运行时与工具编排**：接入 6 个真实接口与 2 个 Mock，支持无依赖并行与依赖串行（tool_call_id 批量回填）。新增工具仅需注册即可无缝接入，不改主循环；异常自动转为 observation 回灌。
* **意图路由与快慢路径调度**：基于前置意图识别，将简单问答分流至 RAG 生成路径，复杂任务进入 ReAct 工具循环，减少简单请求的工具调用开销。
* **状态机强管控知识资产**：前置强制“审核通过且版本有效”，修改后重审重算向量，撤回即标失效。整合专家教学、点评纠偏等来源，封装标准化的人机协同（Human-in-the-loop）接入流程。
* **四级上下文压缩机制**：用量超 80% 触发（工具结果裁剪、历史摘要归档、画像去重合并、关键槽位存档），保障多轮对话状态不丢失。

## 4. 运行时链路

1. API 层接收咨询请求，基于组织校验与独立 `thread_id` 实现**会话隔离**。
2. 前置意图识别进行**快慢路径调度**（简单问答走 RAG，复杂任务进 ReAct 循环）。
3. Harness 按注入式 Loop 组织上下文，程序强制调用知识检索接口，获取审核通过的有效样本。
4. 模型按需调用分析、多路召回（BM25+向量）、工单查询等工具。
5. **执行护栏生效**：单工具 10s 超时、总预算 60s，异常转为 Observation 回灌自我修正。
6. SSE 出口仅放行最终回答增量与引用事件，防止中间态数据泄漏。
7. 低置信度或规则命中，触发转人工（Human-in-the-loop）创建工单。
8. 采集结构化 Trace（request_id、决策摘要、耗时等），按 6 类模式归因失败，沉淀 Badcase。

## 5. 自进化评测与质量保障（重点）

* **自进化效能闭环**：携 Tool 抽象与 `pytest` 样例，交由 Claude Code 生成候选 Diff。在 Docker 隔离环境中执行单调与固定回归子集，重点检查价格、权限等关键用例；人工审核业务语义后合入，对引入回归的变更执行拦截或回滚。
* **自动化门禁拦截**：累计拦截 3 次异常合入（含 1 次回滚），保障 60 条核心回归集 90.0% 通过率。
* **双标注与泛化**：双标注一致率达 93%（κ = 0.854），holdout 泛化差距 2.5pp。

## 6. 已知业务指标与性能边界

* **效能与修复**：42 条基线失败聚类 6 类，实修 36 条（85.7%），复测通过 83.3%；11 次修复验收 9 项，交付中位仅 34 分钟。
* **业务稳定性**：120 条任务覆盖 7 类场景，成功率 65.0% - 90.0%；无依据率 20.0% - 3.3%，转人工率 12.5%。
* **性能与成本**：端到端 P50 8.2s / P95 24.5s；综合成本 0.13 - 0.66 元/次，较纯人工降本 86% - 93%。
* **工程边界**：Docker 配置已提供，本地单机单 worker 运行，向量检索支持扩展至重排模型。

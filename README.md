# 企业级智能售前 Agent 平台

面向企业级售前咨询场景的 Agent 平台原型，构建**工具可插拔、状态可管控、执行可追溯**的 Agent 执行底座（Harness Runtime），并跑通“失败分析 → 变更提案 → 人工审核 → 回归验证”的自进化闭环。

**TL;DR**

1. **底座**：`LLMProvider` + `Tool` 双抽象、注入式 ReAct Loop、统一护栏（单工具 10s / 总预算 60s / 最多 6 步）、SSE 出口过滤。
2. **算法化**：把意图路由、上下文压缩、检索、转人工从规则升级为可校准、可消融、可统计检验的模块，均有 baseline 与消融设计。
3. **质量闭环**：Trace 归因 → 候选 Diff → Docker 隔离 → 统计门禁，五道闸门拦截回归。
4. **状态诚实**：模块按 L0–L3 标注落地程度，L2 为设计待接入，不冒充已实现。

> 算法建模、假设域、实验协议与消融表见 [`docs/DESIGN.md`](docs/DESIGN.md)。本地事件与指标仅用于工程与算法回归验证，不解释为真实商业收益。

## 1. 工程目标与非目标

### 1.1 工程目标

- 提供可本地运行、可演示、可自动化回归测试的售前 Agent 底座。
- `LLMProvider` 与 `Tool` 双抽象 + 注册表，解耦模型接入与业务逻辑。
- Harness 承载 ReAct 循环，统一护栏：单工具 10s 超时、总预算 60s、最多 6 步。
- 多轮状态不丢失：8000 Token 输入预算，超 80% 触发四级压缩。
- Trace 驱动自进化闭环，异常转 Observation 回灌，Docker 隔离 + 门禁拦截。
- 关键启发式模块算法化：成本敏感路由、预算约束上下文选择、证据充分性判定、置信度校准、统计门禁，配套可复现离线实验协议。

### 1.2 非目标

- 不将本地指标解释为真实商业收益；轨迹不含隐藏思维链。
- 不实现真实支付、实时坐席接管、多进程高并发调度。
- 不堆砌无数据支撑的 RL / DPO / 多智能体名词；算法升级须有 baseline、消融与置信区间。
- 不宣称全局最优、跨分布泛化或线上自主持续进化。

## 3. 核心模块速览

> 每节只列**当前实现**与**升级方向**；形式化定义、约束、消融表见 DESIGN 对应章节。

| 模块 | 当前等级 | 一句话现状 | 升级方向 | DESIGN |
|---|---|---|---|---|
| 工具编排 | L0 | 6 真实 + 2 Mock，并行/串行，注册即接入，异常回灌 | CMDP 建模 + 上下文 Bandit 重试 | §2.1 |
| 意图路由 | L0 | 前置识别分流 RAG / ReAct | 代价敏感分类 + 闭式阈值 + 保形校准 | §2.2 |
| 知识资产 | L0 / L1 | 审核通过且版本有效方可检索 | 质量打分器辅助排序（不替代人工） | §2.3 |
| 上下文压缩 | L0 | 80% 触发四级压缩 | 预算约束子模选择 + 硬保护集 | §2.4 |
| 混合检索 | L0 | BM25 + 向量 + Query 改写 + 溯源 | CrossEncoder 重排 + 充分性三区间决策 | §2.5 |
| 转人工 | L0 | 低置信度 / 规则命中转工单 | Mondrian 分层保形控漏转率 | §2.6 |

**3.1 工具编排【L0】**：新增工具仅注册即可接入，不改主循环；硬护栏由 Runtime 拦截，不属于上层优化变量。升级方向为有限时域 CMDP + 上下文 Bandit 重试，工具分布漂移时回退固定规则。

**3.2 意图路由【L0】**：简单问答走 RAG，复杂任务进 ReAct。升级方向为代价敏感二元分类，阈值由代价矩阵闭式推导，配合 Platt 缩放与保形预测；分布偏移触发后冻结路由分数。

**3.3 知识资产【L0/L1】**：前置硬过滤“审核通过且版本有效”，修改重审重算向量，撤回即失效。质量打分仅用于排序与淘汰候选推荐，不替代人工审核，不做模型自动改库。

**3.4 上下文压缩【L0】**：超 80% 触发工具结果裁剪、历史摘要归档、画像去重合并、关键槽位存档，全程保留 `thread_id`。升级方向为预算约束子模选择，设硬保护集（已引用证据、必填槽位、核心实体），数字/单位/条款只允许抽取式裁剪。

**3.5 混合检索【L0】**：BM25 + BGE-M3 混合召回、Query 改写、证据溯源。升级方向为召回 / 重排 / 充分性 / 生成四层解耦，充分性用保形三区间决策，故障归因按串行顺序唯一判定。

**3.6 转人工【L0】**：低置信度或规则命中创建工单。升级方向为风险约束决策，Mondrian 分层保形控制条件漏转率，按场景分层统计，样本不足 30 的场景退回规则阈值。

## 4. 运行时链路

1. API 层接收请求，组织校验 + 独立 `thread_id` 实现会话隔离。
2. 前置意图识别做快慢路径调度：简单问答走 RAG，复杂任务进 ReAct。
3. Harness 按注入式 Loop 组织上下文，程序强制调用知识检索，取审核通过的有效样本。
4. 模型按需调用分析、多路召回（BM25 + 向量）、重排、工单查询等工具。
5. 护栏生效：单工具 10s、总预算 60s、最多 6 步；异常转 Observation 回灌。
6. SSE 出口仅放行最终回答增量与引用事件，防中间态泄漏。
7. 低置信度或规则命中触发转人工建单。
8. 采集结构化 Trace（`request_id`、决策摘要、耗时），按 6 类模式归因，沉淀 Badcase。

## 5. 自进化评测与质量保障（速览）

### 5.1 五道准入闸门

| 闸门 | 一句话规则 | 失败后果 |
|---|---|---|
| G1 归因置信 | 归因器 κ < 0.75 的批次不进闭环 | 退回人工选样 |
| G2 禁止自标注 | 模型标签不得进训练/调参/回归集 | 样本作废 |
| G3 Docker 隔离 | 隔离镜像跑单调性 + 固定回归子集，价格/权限/资质必过 | 拦截 |
| G4 统计门禁 | B=2000 分层 bootstrap 95% CI + 配对置换检验，p>0.05 或下界≤0 拦截 | 拦截或回滚 |
| G5 主动学习 | Badcase 池挑高信息量样本扩回归集，快照归档 | — |

> 闭环为**半监督人工参与迭代**，不存在线上无监督自学习；分布偏移自动冻结策略更新。收益唯一合法度量是回归集通过率与 OOD 衰减。

### 5.2 已报告指标

> 均为**本地单机单 Worker、固定回归分布内**的观测结果；CI 以回归快照为准。

| 指标 | 观测结果 | 样本量 / 统计口径 |
|---|---|---|
| 自动化门禁 | 拦截 3 次异常合入（含 1 次回滚），核心回归集 90.0% 通过 | n=60 回归集；通过率为点估计 |
| 双标注与泛化 | 一致率 93%（κ=0.854），Holdout 泛化差距 2.5pp | 双标注批次；n 与 CI 见快照 |
| 失败修复 | 42 条基线失败聚 6 类，实修 36 条（85.7%），复测通过 83.3% | n=42 |
| 修复验收 | 11 次验收 9 项，交付中位 34 分钟 | n=11，小样本仅作描述 |
| 业务稳定性 | 7 类场景成功率 65.0%–90.0%；无依据率 20.0%–3.3%；转人工率 12.5% | n=120 |
| 性能与成本 | P50 8.2s / P95 24.5s；0.13–0.66 元/次；降本 86%–93% | Trace 快照；成本矩阵见 DESIGN §4 |

## 6. 快速开始

```bash
# 1. 启动服务（含前端多阶段镜像）
docker compose up --build

# 2. 访问咨询平台 / 后台管理
# http://localhost:8888

# 3. 后端回归测试
pytest tests/

# 4. 真实模型 / 浏览器验收（按需）
python scripts/verify_live.py
```

默认本地 SQLite + `state` 数据卷；单机单 Worker；向量检索支持扩展重排模型。

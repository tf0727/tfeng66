# 企业级智能售前 Agent 平台

面向企业级售前咨询场景的 Agent 平台，构建**工具可插拔、状态可管控、执行可追溯**的 Agent 执行底座（Harness Runtime），并跑通“失败分析 → 变更提案 → 人工审核 → 回归验证”的自进化闭环。

**TL;DR**

1. **底座**：`LLMProvider` + `Tool` 双抽象、注入式 ReAct Loop、统一护栏（单工具 10s / 总预算 60s / 最多 6 步）、SSE 出口过滤。
2. **算法化**：意图路由、上下文压缩、检索重排、证据充分性、转人工均实现为可校准、可消融、可统计检验的模块，配套离线实验协议。
3. **质量闭环**：Trace 归因 → 候选 Diff → Docker 隔离 → 统计门禁，五道闸门拦截回归。
4. **可回归**：所有算法模块均有 baseline、消融与置信区间，指标口径统一，参数随回归快照固化。

> 算法实现见 §4，假设与降级策略见附录 A，实验协议见 §6.2。本地指标仅用于工程与算法回归验证，不解释为真实商业收益。

## 1. 工程目标与非目标

### 1.1 工程目标

- 提供可本地运行、可演示、可自动化回归测试的售前 Agent 底座。
- `LLMProvider` 与 `Tool` 双抽象 + 注册表，解耦模型接入与业务逻辑。
- Harness 承载 ReAct 循环，统一护栏：单工具 10s 超时、总预算 60s、最多 6 步。
- 多轮状态不丢失：8000 Token 输入预算，超 80% 触发四级压缩。
- Trace 驱动自进化闭环，异常转 Observation 回灌，Docker 隔离 + 门禁拦截。
- 关键模块算法化并落地：成本敏感路由、预算约束上下文选择、检索重排与证据充分性、置信度校准、统计门禁，配套可复现离线实验协议。

### 1.2 非目标

- 不将本地指标解释为真实商业收益；轨迹不含隐藏思维链。
- 不实现真实支付、实时坐席接管、多进程高并发调度。
- 不堆砌无数据支撑的 RL / DPO / 多智能体名词；算法实现须有 baseline、消融与置信区间。
- 不宣称全局最优、跨分布泛化或线上自主持续进化。

## 4. 算法实现与评测

> 以下模块均在附录 A 的假设域内生效；违例按附录 A 降级。硬护栏由 Runtime 强制，不属于上层优化变量。所有指标按 §6.2 协议在固定回归集与 Holdout 上报告。

### 4.1 工具编排——有限时域 CMDP + 上下文 Bandit

**实现**

- 6 个真实接口 + 2 个 Mock，无依赖工具并行、依赖工具按 DAG 串行，`tool_call_id` 批量回填；新增工具仅注册即可接入，不改主循环。
- 异常自动转 Observation 回灌，并沉淀 Badcase；Runtime 硬护栏强制单工具 10s、总预算 60s、最多 6 步，策略输出违例动作时拒绝并记 `guardrail_violation`，样本入 Badcase 池。
- 编排策略以有限时域 CMDP 建模：状态 $s_t=(T_{used},K_{step},C_{token},E_{slot},G_{done},F_{recent})$，动作为下一 DAG 节点集合、参数填充、并行分组、重试与提前终止。
- 重试子策略用上下文 Bandit：Arm 为不重试 / 同参数重试 / 修正参数重试 / 降级 RAG / 终止工具流；上下文特征为工具历史成功率、剩余预算、失败类型、证据完备度；离线用 IPS / 双重稳健估计。
- 策略排序奖励 $r=\mathbb{I}(\text{任务正确完成})-\lambda_1\Delta C_{token}-\lambda_2\Delta latency$，$\lambda_1,\lambda_2$ 在验证集标定后固定，Holdout 不调优。

**指标与消融**：按串行依赖 / 独立并行 / 混合拓扑分组报告任务成功率、平均步数、超时率、参数准确率、P50/P95、调度错误率，禁止混合平均。消融：全串行、关闭 Bandit、Bandit 退回规则表。兜底：非法 DAG 或参数越界自动回退串行基线，样本标调度失败入 Badcase 候选池。

### 4.2 成本敏感意图路由

**实现**：代价敏感二元分类，$y\in\{RAG,ReAct\}$。

- Oracle 标签由人工双标注：仅当知识库静态证据无法保证正确、必须调外部工具时 $y^*=ReAct$；辅助判据为 RAG 引用无法指向任一审核通过的有效样本。
- 代价矩阵在验证集固定：$C_{01}$（FP，本应 RAG 误进 ReAct）为多余时延与 Token；$C_{10}$（FN，本应 ReAct 误走 RAG）为高风险无依据回答，由验证集无依据率 × 单次风险权重标定，并做敏感性分析。
- 阈值取闭式解 $\tau^*=\frac{C_{01}}{C_{01}+C_{10}}$，由代价矩阵推出而非人工拍定；验证集做代价扫描，Holdout 只做最终评估。
- 概率经 Platt 缩放校准（ECE 目标 < 0.05，未达标该路由不启用），叠加保形预测；不确定区间统一走 ReAct 保守兜底。
- 分布偏移检测触发后冻结路由分数，切回关键词规则基线。

**指标与消融**：路由准确率、FP 率、FN 漏风险率、RAG 分流占比、Token 降幅、端到端 P95、ECE。基线：关键词规则、全 ReAct、全 RAG、未校准阈值 0.5。消融：移除保形校准、移除代价敏感阈值、去除单特征子集。

### 4.3 知识资产质量管控

**实现**：知识有效性作为检索前置硬过滤，“审核通过且版本有效”方可进入召回；修改后重审重算向量，撤回即标失效。质量打分器输入人工点评、历史召回下游正确率、引用频次、否定反馈，输出仅用于知识排序与淘汰候选推荐，**不替代人工审核**，不做模型自动改库。

**指标**：检索命中率、淘汰候选准确率、审核后失效率。**边界**：不解决知识库 OOD 覆盖不足；知识缺失导致的错误不归因于资产状态机。

### 4.4 预算约束下的四级上下文压缩

**实现**

- 超 80% 触发四级压缩：工具结果裁剪、历史摘要归档、画像去重合并、关键槽位存档，全程保留 `thread_id`。
- 压缩建模为预算约束子模集合选择：候选单元 $U$ 为历史轮次、证据片段、业务槽位、工具返回、摘要；在 $token(S)\le B$ 下最大化 $\sum w_i\mathbb{I}(i\text{ 为回答必要信息})$。
- $w_i$ 由离线人工标注“是否为必要证据/槽位”拟合，不使用模型自评。
- 硬保护集禁止删除：已引用证据 ID、必填业务槽、用户核心诉求实体；保护集仅允许裁剪文本冗余，不可抹除条目标识。
- 求解用贪心 + MMR 冗余惩罚，价值函数按近似子模处理，贪心给出相应近似保证，不宣称最优。
- 压缩顺序在验证集策略池搜索 Pareto 组合（准确率、引用保持率、Token 降幅），Holdout 不参与搜索。

**指标与消融**：长对话 QA 准确率、引用保持率、Token 降幅、压缩耗时、引用断裂率。基线：固定头部截断。消融：移除重要性打分、关闭硬保护集、固定压缩顺序、逐级去掉某一级。

**边界**：仅做信息筛选与摘要改写，不篡改原始证据、不改知识库；数字、单位、条款编号只允许抽取式裁剪。

### 4.5 混合检索、重排与证据充分性

**实现**

| 层级 | 实现 | 指标 |
|---|---|---|
| 召回 | BM25 + BGE-M3 向量，固定 Top-k | Recall@k、MRR |
| 重排 | CrossEncoder 重排 | nDCG@k、top-1 命中率 |
| 充分性 | 三区间决策：充分 / 不充分 / 不确定 | 充分性 F1、拒答率、ECE |
| 生成 | 基于证据生成并附引用 | 引用准确率、无依据率 |

- 充分性标签由人工二元标注“当前 TopN 证据是否足够回答”；κ < 0.75 的批次剔除。
- 三区间决策：高置信充分直接生成；高置信不充分拒答并提示补充；不确定区间保守转人工。
- 故障归因按串行顺序唯一判定：召回失败 → 重排失败 → 证据不足 → 生成越界。
- 无 gold 样本单列 $D_{nogold}$，不参与召回/重排指标，只评生成与工具维度。

**指标与消融**：Recall@k、nDCG@k、充分性 F1、无依据率、引用准确率、拒答率。消融：关闭重排、关闭充分性判定。

**边界**：充分性仅评估当前已召回证据池，无法识别知识库全域缺失的 OOD；缺失不计入充分性责任。

### 4.6 转人工风险覆盖

**实现**：风险约束分类决策，$\min \text{工单率}\ \text{s.t.}\ \Pr(\text{漏转})\le\alpha$。

- 标签：当前证据与模型能力无法可靠回答时标为需转人工。
- 阈值用分层保形：按报价 / 权限 / 方案对比 / 交付周期分层，控制条件覆盖率；$\alpha$ 默认 0.05，敏感性报告 0.02/0.05/0.10/0.15 四点；分位数在验证集求取，Pareto 在验证集生成，Holdout 只评估一次。
- 混淆矩阵：TP 应转已转；FN 应转未转且输出错误答案（核心风险）；FP 无需转而建单（仅人工成本）。

**指标与消融**：工单率、漏转率、风险覆盖率（$1-\text{漏转率}$）、AUC、ECE，按场景分层。消融：移除保形校准、纯规则命中、边际保形不分层。某场景 $n<30$ 时退回规则阈值并标注样本不足。

## 5. 运行时链路

1. API 层接收请求，组织校验 + 独立 `thread_id` 实现会话隔离。
2. 前置意图识别做成本敏感路由：简单问答走 RAG，复杂任务进 ReAct。
3. Harness 按注入式 Loop 组织上下文，程序强制调用知识检索，取审核通过的有效样本。
4. 模型按需调用分析、多路召回（BM25 + 向量）、CrossEncoder 重排、工单查询等工具。
5. 护栏生效：单工具 10s、总预算 60s、最多 6 步；异常转 Observation 回灌。
6. SSE 出口仅放行最终回答增量与引用事件，防中间态泄漏。
7. 低置信度或规则命中触发转人工建单。
8. 采集结构化 Trace（`request_id`、决策摘要、耗时），按 6 类模式归因，沉淀 Badcase。

## 6. 自进化评测与质量保障

### 6.1 五道准入闸门

| 闸门 | 规则 | 失败后果 |
|---|---|---|
| G1 归因置信 | 归因分类器报告 macro-F1 与 κ；κ<0.75 批次禁止进入闭环 | 闭环停用，退回人工选样 |
| G2 禁止自标注 | 模型生成标签不得进训练/调参/回归集；候选 Badcase 须人工复核后入池 | 违规样本作废 |
| G3 Docker 隔离 | 隔离镜像执行单调性检查 + 固定回归子集（价格/权限/资质必过） | 拦截 |
| G4 统计门禁 | B=2000 分层 bootstrap 95% 双侧 CI + 配对置换检验；$p>0.05$ 或通过率差下界 $\le 0$ 拦截 | 拦截或回滚 |
| G5 主动学习 | Badcase 池挑高信息量样本扩回归集；快照版本归档，不随意追加 | — |

> 闭环为半监督人工参与迭代，不存在线上无监督持续自学习；分布偏移触发后自动冻结策略更新。收益唯一合法度量为回归集通过率与 OOD 衰减，不表述为“模型能力提升”。

### 6.2 实验协议

- **数据切分**：Train（训练/调参）/ Val（Pareto、阈值、消融筛选）/ Holdout（全程只跑一次）/ OOD 子集（库外、新意图、异常参数）。OOD 单独上报，不计入主性能。
- **Baseline 全集**：规则路由 + 固定截断压缩 + BM25 无重排 + 无充分性判定 + 固定阈值转人工。
- **消融**：单变量，一次仅移除一个组件。
- **统计规范**：点估计 + bootstrap 95% CI；$n<30$ 只报区间不作显著性宣称；$n<10$ 仅定性描述。
- **失败归因（6 类，与 §4.5 顺序对齐）**：召回失败、重排失败、证据不足、工具调用错误、上下文丢失、生成越界幻觉。
- **参数与成本快照**：Token/时延成本矩阵、代价矩阵、保形目标、压缩权重、阈值随回归快照固化；任何改动走全套消融 + Holdout。
- **边界**：本地单机单 Worker，指标仅代表本地评测事件。
